新規申込でも8文字以上の見本パスワードを設定できます。申込確認とアルバムは同じアカウントです。代表幹事は「幹事権限」で幹事を指定・解除します。

「会計・収支」で経費を登録→別の幹事で承認→CSVの出金を確認→経費との照合。分割・一括・取消を試せます。領収書は架空のJPEG/PNG/PDFだけを使用してください。自己承認・二重精算は拒否します。

## 会費の振込先口座（2026-10-30）

期限・大会設定の「会費の振込先口座」に銀行名・支店名・普通／当座・口座番号（7桁）・口座名義を設定します。管理者だけが保存でき、幹事は閲覧のみ。PHP版ではCSRFとサーバー側のowner権限チェックを行います。一般の大会設定の保存や偽の追加項目では口座情報を上書きできません。変更理由と変更前後を操作履歴へ保存します。全空欄で保存すると未設定に戻します。

保存した情報は参加申込の会費・期限の案内と本人の申込確認に表示します。未設定の場合は準備中と表示し、架空の銀行・口座を既定値には設定しません。口座番号は文字列で先頭0を保持し、全角数字を半角に統一します。本番用の実口座はまだ登録していません。

公開GitHubサンプルの設定はブラウザー内だけで、他端末と共有されません。実口座を入力せず架空情報で確認してください。本番の共有設定と権限制御はPHPサーバー版で行います。銀行接続や実振込は行いません。
