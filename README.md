## まず試す

申込確認・フォトアルバム・幹事画面を開くとログインの見本が表示されます。

|役割|見本メール|見本パスワード|
|---|---|---|
|参加者|sample3@example.test|Sample1987!|
|幹事|sample2@example.test|Sample1987!|
|代表幹事|sample1@example.test|Sample1987!|

新規申込でも8文字以上の見本パスワードを設定できます。申込確認とアルバムは同じアカウントです。代表幹事は「幹事権限」で幹事を指定・解除します。

「会計・収支」で経費を登録→別の幹事で承認→CSVの出金を確認→経費との照合。分割・一括・取消を試せます。領収書は架空のJPEG/PNG/PDFだけを使用してください。自己承認・二重精算は拒否します。

## 今回の操作

- トップ下部またはメニュー「お問い合わせ」から架空の内容を保存。代表幹事／幹事で「お問い合わせ」を開き、受付番号から返信を保存。「開発メール」で宛先と本文を確認できます。実送信はありません。
- 代表幹事の「クラス幹事」で各クラス最大3名を指定。「申込確認」に自分のクラスの担当者を表示します。管理権限の付与とは別です。
- 「写真管理」で場面別アルバムを追加・改名・並べ替え・非表示にし、写真を分類できます。
- 「みんなの参加予定」は氏名カード、クラス別人数と全体人数を表示。

## 公開サンプルの範囲

これは**ブラウザー内保存の架空データ専用サンプル**です。ログインは画面の体験で、本物の認証・閲覧制限ではありません。GitHubのプログラムと見本アカウントは公開です。実氏名・連絡先・銀行CSV・同窓会や卒業アルバム写真・実領収書は登録しないでください。端末間の共有・実メール・銀行接続・実返金はありません。

データ155件、参加予定152人を初期表示。追加した写真・領収書・操作ログはそのブラウザーだけに保存。ブラウザー容量が小さいため大量添付には使えません。幹事・代表幹事も見本であり現実の幹事本人の権限ではありません。

## 本番候補向けPHP版

`server/README.md`に起動・移行・実装範囲を記載。`server-source.zip`にも同じサーバーソースを保存。

サーバー版はPHP/PDOで本人認証・幹事権限・非公開ファイル取得・DB保存を行います。開発SQLite、本番候補MySQL。サンプルのブラウザー内データは自動移行しません。GitHub PagesではPHPは動かないため、実行はMac内または将来のレンタルサーバーです。

MySQL/さくら実機、実メールの設定と到達確認・再設定・各種PDF・決算締め・その他収入や返金伝票などは未完成／未検証。現時点で実受付を開始できる状態と表示しません。

公開するのはコード・オリジナルイラスト・架空テストのみ。秘密設定、DB、銀行原本、添付、監査ログはGit対象外。

アルバムは「フォトアルバム」1件から開始。名前・件数は固定せず、幹事の写真管理画面で追加・改名します。以前の未編集の仮3分類だけは写真を残して整理し、独自に変更した名前は保持します。
