# 岡崎北高等学校1987年卒同窓会 公開操作サンプル

公開URL：https://yasu1401.github.io/okazakikita1987-reunion-sample/

LINEでURLを共有できます。ログイン不要。本番の申込受付ではありません。

申込・10クラスの名簿と人数・申込変更・欠席申請・幹事管理・架空UFJ CSV照合・入金操作ログ・期限個別設定・写真の表示と保存を体験できます。初期データは架空の155件、参加予定152人。

このサンプルはブラウザー内保存です。ほかの端末・利用者とはデータを共有しません。実際の個人情報、銀行明細、写真は入力しないでください。会費・期限は仮設定。実メール送信、銀行接続、実返金はありません。

`index.html` はHTML/CSS/JavaScriptとSVGイラストをまとめた単一ファイルです。表示用PNG以外に依存ライブラリーやサーバーは不要です。校舎・風景・会食の画像はオリジナルイラストで、学校・ホテルの実写真ではありません。

## 試す順番

1. 参加申込→架空情報を自動入力→確認・確定。
2. クラス別・全体人数の反映を確認。申込確認から変更・欠席申請。
3. 幹事画面→CSV・入金照合→前半の架空CSVを取込。再取込と期間重複も確認。
4. K87-00003の明細を理由付きで確認→8,000円を割当。
5. 入金操作ログで担当者・変更前後・理由を見る。幹事A/Bの切替、割当取消・訂正も可能。
6. 期限・大会設定で申込・入金・修正・キャンセル期限を個別に指定。
7. アルバムでイラストを表示・ダウンロード。写真管理でテスト画像を端末内に追加。

## 制限

幹事画面もパスワードなしで公開する画面サンプルです。入金ログは端末内だけで、実運用の共通監査ログ・改ざん防止を保証しません。本番では認証・共通DB・写真保護・サーバー側の入金ログを別途実装します。

Nodeのロジックテスト12項目が成功。ブラウザーで申込確定、CSV取込、明細判定、入金割当、ログ表示、PC・375px幅の表示を確認。LINEアプリ内の動作・リンクプレビューは実機未確認です。

学校公式サイトではありません。独自ドメイン・有料サーバー契約はしていません。
