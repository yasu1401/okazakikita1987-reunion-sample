# 欠席取消・再参加・返金の追加

2026年11月3日。

## 操作

1. 申込確認で欠席申請を送った後、幹事確認前なら本人が「欠席申請を取り消して出席に戻す」を選ぶ。
2. 取消確定後は本人が「再参加を希望する」を選び、幹事が「欠席・再参加・返金」で承認または見送りを判断する。
3. 返金が必要なら同画面で予定額と理由を登録。実際の送金は銀行側で別途行う。
4. 銀行側で送金した日・確認メモを記録し、取り込んだ確認済み出金と照合する。銀行CSVの入金割当・経費照合と同じ出金を重複利用できない。
5. 誤記は理由付きで照合取消・記録訂正・予定取消。履歴を削除せず、実送金を取り消す処理とは区別する。

## 仮の運用

本人操作は内容変更期限内。取消確定後の再参加は幹事承認と定員確認を必須とする。再参加時も当初会費と申込番号を維持する。返金予定が残る間は再参加を承認せず、予定を先に整理する。返金記録済みなら入金から返金を差し引き、再参加後の必要会費を表示する。

キャンセル料を自動計算しない。幹事が返金基準と金額を確認して入力する。送金機能はなく、公開サンプルの記録はすべて架空で端末内保存。

## 確認

既存PHP99項目、新規業務18項目、HTTP157項目、JavaScript51テストが合格。本人取り消し、幹事承認、二重送信、超過返金、二重割当、記録訂正、同じ番号で再参加、返金分の会費再案内を含む。ブラウザーで本人の申請取り消し、幹事による取消確定、返金予定と実施記録、再参加承認と差額表示を操作した。ローカルDBは変更前にバックアップし、追加テーブルをマイグレーションした。

さくら・MySQL実機、実際の銀行送金、実メール送信は未確認。
