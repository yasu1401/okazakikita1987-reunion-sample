# アルバム別ダウンロード設定

- 管理画面のアルバム追加・編集に「写真のダウンロード」設定を追加。初期値は不可。既存の卒業アルバム・みんなの投稿写真も未設定なら不可。
- 一覧のダウンロード操作と拡大ビューのリンクを連動。閲覧のみの画像にも拡大・前後移動は利用可能。
- 設定はブラウザー保存・バックアップ対象。設定変更前後と理由をログへ保存。
- PHP版はDB列追加、保存、ビュー、ファイル取得時の許可判定を追加。導入時はREADMEのmigrateを実行。

## 確認結果

隔離したChromeと架空データでPC幅1440px／スマホ幅390pxの各14項目、合計28項目が成功。JSエラーなし。

初期値、管理フォーム、不可時の一覧と拡大、許可保存と監査ログ、localStorage保存、参加者の許可表示、投稿アルバムとの設定独立、許可取消、ドメイン判定、参加者の設定拒否を確認。

PHP実行環境がなく、PHP版の構文・DB移行・HTTP403・許可時の実ダウンロードは未確認。さくら・MySQL・実機スマートフォン・実際のダウンロード保存も未確認。

この設定はサイトのダウンロード機能の提供可否を制御するもの。表示画像の端末保存やスクリーンショットを完全に防ぐものではない。
