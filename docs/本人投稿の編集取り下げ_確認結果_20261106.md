# 本人投稿の編集と取り下げ

本人の参加者投稿のみ、タイトル・表示用投稿者名・コメントの変更と掲載取り下げを追加。全体アルバムから本人投稿一覧へ移動できます。理由と変更前後を記録。取り下げはdeleted=1・published=0にして履歴を保管します。本人からの復元は不可、管理画面の復元は従来どおり非公開で行います。非公開状態、アルバム、順番は本人編集で変更しません。

隔離Chrome、架空JPEG・架空アカウント、幅1440px/390pxの各17項目、計34項目成功。JSエラーなし。
本人限定の一覧・フォーム、管理項目の非表示、フォームからの保存とlocalStorage・監査ログ、他人の編集/取り下げ拒否、幹事登録写真の編集拒否、管理操作拒否、改変した公開・移動・順番の無視、取り下げ後のアルバム非表示と本人画面表示・再編集拒否、管理者の復元、アルバムの入口を確認。
