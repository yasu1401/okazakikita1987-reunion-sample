# 担当・役割管理

幹事画面の「担当・役割管理」を開きます。

- 管理者：「担当を追加」から役割と登録者を選びます。1人で複数担当も可能です。
- 外部の司会者など：「外部協力者」を選び、氏名と任意の連絡メモを登録します。参加申込やログイン権限は作りません。
- 「その他」を選ぶと任意の担当名を入力できます。
- クラス幹事：「クラス幹事の設定」から従来どおり設定します。既存の指定や公開名簿の表示は維持します。
- 幹事は一覧を閲覧できます。氏名・役割・担当内容の検索、役割・クラス・区分・状況で絞り込み、表示中の一覧CSVを利用できます。
- 「自分の担当」ボタンで自身の担当を一覧表示できます。申込確認にも「あなたの担当」を表示します。
- 担当者の氏名を押すと詳細を確認できます。編集は管理者のみです。
- 担当終了・解除は状況を変更して記録します。変更理由・変更前後は「入金操作ログ（管理操作も含む）」に保存されます。

担当名の登録と、会計や参加者情報を操作するログイン権限は別です。担当者を指定しただけで管理権限が増えることはありません。連絡メモと幹事内メモは一般公開せず、本人向け担当案内にも載せません。

GitHubサンプルで入力するのは架空の情報のみ。端末内保存のため他の幹事の端末とは共有されません。PHP版にも追加し、18項目の業務テスト・全173項目のHTTPテスト・全56件のJavaScriptテストが合格しています。390px幅でフォームと検索欄の1列表示、表内の横スクロールを確認しました。さくら・MySQL実機とスマートフォン実機は未検証です。
