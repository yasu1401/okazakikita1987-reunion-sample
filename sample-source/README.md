## 重要な範囲

- 本番の同窓会への申込受付ではありません。架空のデータだけを使用してください。
- 初期データは架空の申込155件、参加予定152人・全10クラス。人物は実在の卒業生と関係ありません。
- 内容はブラウザー内のlocalStorageに保存します。ほかの利用者・端末とは同期しません。LINE内ブラウザーとSafari等でも別保存になります。
- 幹事画面も写真ページも公開サンプルとして認証なしです。実際の個人情報・銀行CSV・同窓会写真を入力しないでください。
- 写真追加はこの端末だけ。サーバーへのアップロード・実メール送信・銀行接続・実返金はありません。
- 校舎・風景・会食画像はオリジナルのイラストであり、実際の学校やホテルの写真ではありません。
- 開催日は2028年○月○日（未定）、会場は岡崎ニューグランドホテル。会費8,000円や各期限は操作用の仮値です。
- 本番ではPHP/MySQL等の共通DB、本人・幹事認証、写真保護、サーバー側ログ保存などを別途実装・検証します。このまま実受付に転用しないでください。

## お試しの順番

1. 参加申込→「架空のサンプル情報を自動入力」→確認→確定。
2. クラス名簿の人数が増えることを確認。「申込確認」で自分の申込・欠席変更申請を体験。
3. 幹事画面→CSV・入金照合→「前半の架空CSVで試す」。同じボタンを押して同一取込を抑止。「重複期間」で全列一致候補を確認。
4. 申込番号003を含む明細の「確認・割当」→理由を入れて判定→理由を入れて8,000円割当。
5. 入金操作ログで担当者・日時・変更前後・理由を確認。参加者詳細から割当取消・訂正が可能。
6. 「操作する幹事」をA/Bに切り替えて、別担当者の操作を記録。
7. 期限・大会設定で申込・入金・修正・キャンセル期限を別々に設定。期限判定用日付を進め、期限内外の動作を確認。
8. 写真管理でJPEG/PNGの見本を追加（端末内のみ）→非公開で確認→公開→アルバム表示・個別ダウンロード。
9. デモのバックアップJSONを保存・復元可能。初期化は初期化前バックアップをダウンロードしてから実行。

## ソースとローカル起動

公開リポジトリには、サイト全体を埋め込んだ単一の `index.html` を配置しています。ローカル制作フォルダーの分割ソースは `dist/`、公開用の単一ファイル版は `github-pages/` です。

```bash
python3 -m http.server 8787 --bind 127.0.0.1 --directory dist
```

http://127.0.0.1:8787 は起動したPC内だけで使う確認用アドレスです。他の端末へ共有する場合は上のGitHub PagesのHTTPS URLを使ってください。PythonがないMacではPythonの準備が必要です。サイト本体にNode・Python・生成AI APIは不要です。
