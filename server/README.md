## Macで起動

PHPをインストール済みとは仮定しません。必要：PHP8.2以上（推奨8.4の最新パッチ）、pdo_sqlite / pdo_mysql / session / filter / fileinfo / mbstring / GD（JPEG・PNG）/ exif。

1. PHPがない場合は公式案内 https://www.php.net/manual/ja/install.macosx.packages.php に沿ってHomebrew等で導入します。Homebrew導入後は`brew install php`。これは利用者自身のMacへのソフト追加です。
2. ターミナルでこの`server`フォルダーへ移動し、`php -v`、`php -m`で確認します。
3. `php scripts/manage.php init` → `php scripts/manage.php seed` → `php scripts/manage.php seed-community`（seedは空DB・開発環境のみ。seed-communityは架空アカウントだけの開発DBに2名／クラスを指定）。
4. `php -d upload_max_filesize=6M -d post_max_size=8M -S 127.0.0.1:8790 -t public public/router.php`（または`start.command`を開く）
5. http://127.0.0.1:8790/ を開きます。終了はターミナルのControl+C。

見本：sample1@example.test＝代表幹事、sample2@example.test＝幹事、sample3@example.test＝参加者。パスワードは全て`Sample1987!`。架空30件。実受付にはこのアカウントを使わないでください。

開発用SQLiteは`var/reunion.sqlite`。再起動しても残ります。`config.example.php`から始まり、独自設定は無視対象の`config.local.php`へコピーします。

この作業でPHP公式ソース8.4.27をSHA256照合のうえ一時フォルダーでビルドしました。実行ファイルは`/tmp/php-8.4.27/sapi/cli/php`。一時ファイルなのでMacの再起動等で失われる可能性があり、通常のPHPインストールの代用にはしません。このMac用には無視対象の`var/bin/php`にもコピーし、`start.command`から使えるようにしました。キャッシュ内の共有ライブラリーを消した場合は通常のPHP導入が必要です。このビルドにはGD（JPEG/PNG）・mbstring・exif・PDO SQLite/MySQLを有効にしました。画像再エンコード、保護ダウンロード、Shift-JIS取込はローカルHTTPテストで確認しています。MySQL接続自体は未検証です。

現在は `mode=development` / `mail_enabled=false`。外部送信は行いません。`php scripts/mail_queue.php` は待ち件数を表示するだけです。
