# 岡崎北1987同窓会 サーバー版（開発中）

2026-10-29。将来さくら等に配置するPHP/PDO版。実際の個人情報や銀行明細での運用開始前です。
公開GitHub Pages版は別の、架空データを使うブラウザー内デモです。本番用の認証ではありません。

## 現在実装したもの

- PHP側の個人登録、メール＋パスワード認証、ログアウト、30分の無操作失効、ID再生成、CSRF、ログイン試行制限。
- 本人の申込確認・期限内変更・欠席申請、幹事の取消判定。会費は登録時に保持し、変更後も履歴を残す。
- 8文字以上のパスワード。`password_hash` / `password_verify`。4桁だけのPINは不可。
- 一般参加者／幹事／代表幹事。代表幹事だけが幹事を付与・解除。公開申込や自分のページから昇格できない。
- 一般公開のクラス別名簿は掲載同意のある表示名だけ。人数は非掲載者も含む。
- 保護アルバム、クラス別表示、画像取得時のログイン・公開状態・参加状態・期限の確認。ログイン済み参加者は他クラスにも切替可能。
- 幹事による非公開写真登録→確認→公開。画像・領収書は`public/`外でランダムな名前で保管。JPEG/PNG画像はGD再エンコードでメタデータを除く。PDF領収書は添付ダウンロードのみ。
- 経費・立替申請、任意の領収書添付（JPEG/PNG/PDF、5MB）、別幹事による承認、銀行出金との一括／分割照合と取消。
- UFJの管理行と9列見出し、UTF-8/Shift-JIS、日付6/8桁・区切り、カンマ金額・空欄、元バイト列保持、行別エラー。
- 同一ファイルSHA256で再取込抑止。期間重複の全列一致は削除せず要確認。同日同額同名義でも別残高は保持。名義の格納列は未確定として表示。
- 手動の入出金確認、参加費の一括・分割割当、不足・過払いを差額で表示。出金は承認経費へ割当。二重割当防止、取消履歴。
- 金額は整数円。データ更新と監査ログを同じトランザクションで保存。SQLite/MySQLで共通ロック行を更新して割当を直列化する。
- 開始残高＋確認済銀行入金−確認済銀行出金と、経費未精算額を別表示。経費登録だけでは現金残高は変わらない。
- 経費・参加者・監査ログのCSV出力、数式対策、各期限の個別設定。

## Macで起動

PHPをインストール済みとは仮定しません。必要：PHP8.2以上（推奨8.4の最新パッチ）、pdo_sqlite / pdo_mysql / session / filter / fileinfo / mbstring / GD（JPEG・PNG）/ exif。

1. PHPがない場合は公式案内 https://www.php.net/manual/ja/install.macosx.packages.php に沿ってHomebrew等で導入します。Homebrew導入後は`brew install php`。これは利用者自身のMacへのソフト追加です。
2. ターミナルでこの`server`フォルダーへ移動し、`php -v`、`php -m`で確認します。
3. `php scripts/manage.php init` → `php scripts/manage.php seed`（空DB・開発環境のみ）。
4. `php -d upload_max_filesize=6M -d post_max_size=8M -S 127.0.0.1:8790 -t public public/router.php`（または`start.command`を開く）
5. http://127.0.0.1:8790/ を開きます。終了はターミナルのControl+C。

見本：sample1@example.test＝代表幹事、sample2@example.test＝幹事、sample3@example.test＝参加者。パスワードは全て`Sample1987!`。架空30件。実受付にはこのアカウントを使わないでください。

開発用SQLiteは`var/reunion.sqlite`。再起動しても残ります。`config.example.php`から始まり、独自設定は無視対象の`config.local.php`へコピーします。

この作業でPHP公式ソース8.4.27をSHA256照合のうえ一時フォルダーでビルドしました。実行ファイルは`/tmp/php-8.4.27/sapi/cli/php`。一時ファイルなのでMacの再起動等で失われる可能性があり、通常のPHPインストールの代用にはしません。このビルドにはGD（JPEG/PNG）・mbstring・exif・PDO SQLite/MySQLを有効にしました。画像再エンコード、保護ダウンロード、Shift-JIS取込はローカルHTTPテストで確認しています。MySQL接続自体は未検証です。

## 確認手順

1. 参加申込→8文字以上のパスワードで登録→自分の申込だけを確認。
2. 参加者アカウントで幹事URLを開くと拒否される。
3. 幹事sample2で経費・見本PDF領収書を登録。
4. sample2で自分の経費を承認しようとすると拒否。sample1で承認。
5. 架空のUFJ CSVをアップロード→出金明細を確認→経費IDと金額・根拠を指定して照合。
6. 同額を再割当すると拒否。取消理由を入れて解除すると再照合可能。
7. 一般参加者から領収書のURLへ直接アクセスすると拒否。
8. 写真はGD有効環境で登録→非公開→公開→参加者がダウンロード。写真を非公開に戻すと直接URLでも拒否。
9. 操作ログ、経費CSV、再起動後の残存を確認。

## さくらへの移行

- サーバー契約・公開はまだ実施していない。GitHubへはプログラムと架空のテストだけを登録する。
- PHP/MySQL対応プランを選び、`config.local.php`で`mode=live`、PDO DSNを`mysql:host=...;dbname=...;charset=utf8mb4`に変更。
- `src/`、設定、`var/`はホームページ公開領域外に配置。公開するのは`public/`の内容だけ。設定パスやディレクトリ構成を移転先に合わせて調整する。全フォルダーをwwwへアップしない。
- MySQLは`php scripts/manage.php init`で新規テーブル作成。SQLiteをファイルコピーしてもMySQLにはならない。データ移送スクリプトは別途用意し、ID・割当・添付・ログを移して件数と金額を照合する（現時点で移送ツール未実装）。
- 本番は空DBから代表幹事をCLI作成：`php scripts/manage.php owner 幹事メールアドレス`。パスワードは対話入力。開発用seedは使わない。
- HTTPS・Cookie・ファイルアクセス・メール・バックアップ復元・同時割当を本番同等環境で検証後に実受付へ切り替える。

## バックアップと復元

- 書込みを止めてから`var/`と`config.local.php`を暗号化して別の保存先へコピー。SQLiteではDB・添付・ログが同じ時点になるようにする。
- MySQLでは書込みを止め、mysqldumpと添付フォルダーを同時点で保存。資格情報をコマンド引数・Gitへ入れない。
- 復元はテスト環境へ先に戻し、件数・会計額・添付取得・権限を確認してから本番へ。復元の全手順は本番環境で未検証。
- テストデータ初期化はサーバー停止→`var`をバックアップして別名へ移動→`init`→`seed`。実データがある場所でseedを実行しない。
